🚀 Commandes Terminal - Gestion Garage

💻 Environnement Virtuel

Supprimer un environnement (en cas d'erreur)
rm -r venv
Créer un environnement virtuel
python -m venv venv
À faire sur chaque nouvelle machine
Activer l'environnement virtuel
Windows: venv\scripts\activate.ps1
Linux/Mac/Codespace: source venv/bin/activate
À faire sur chaque nouvelle machine

📦 Dépendances

Installer les dépendances npm
npm install
Installe les modules selon package-lock.json
Installer les dépendances Python
pip install -r requirements.txt
À faire sur chaque nouvelle machine
Mettre à jour les dépendances Python
pip freeze > requirements.txt
Générer une clé secrète Django
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"

🐍 Django

Lancer le serveur Django (Codespace)
python manage.py runserver 0.0.0.0:8000
⚠️ Ne pas oublier de mettre le port 8000 en public
Lancer le serveur Django (local)
python manage.py runserver
Créer les migrations
python manage.py makemigrations
Appliquer les migrations
python manage.py migrate
Lister les superusers Django
python manage.py shell -c "from django.contrib.auth.models import User; [print(u.username) for u in User.objects.filter(is_superuser=True)]"
Créer un superuser Django
python manage.py createsuperuser
Charger des données de test
python manage.py loaddata fixtures/demo_data.json

⚛️ React

Lancer le serveur React
npm start

🐳 Docker

Lancer les conteneurs Docker
docker-compose up
Lancer les conteneurs Docker en arrière-plan
docker-compose up -d
Arrêter les conteneurs Docker
docker-compose down
