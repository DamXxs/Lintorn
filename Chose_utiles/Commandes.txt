// SUPPRIMER UN ENVIRONNEMENT // # EN CAS DE FOIRAGE
    ** rm -r venv **

// CREER UN ENVIRONNEMENT  // # LE FAIRE A CHAQUE NOUVELLE MACHINE #
    ** python -m venv venv **

------------------------------------------------------------------

// OUVRIR UN ENVIRONNEMENT (venv) //
    __Sous windows__
        ** venv\scripts\activate.ps1 **
    
    __Sous Codespace__
        ** source venv/bin/activate ** # A FAIRE A CHAQUE NOUVELLE MACHINE #

------------------------------------------------------------------

// INSTALLER LES NPM // # A FAIRE A CHAQUE NOUVELLE MACHINE #
    ** npm install ** # Les modules sont installer par rapport a package-lock.json #

// Lancer le serveur React //
    ** npm start **

-------------------------------------------------------------------

// Lancer le serveur Django //
    __Lancer le serveur depuis Codespace__
        ** python manage.py runserver 0.0.0.0:8000 **
        /!\ NE PAS OUBLIER DE METTRE LE PORT 8000 EN PUBLIC /!\
    
    __Lancer le serveur depuis l'ordi__
        ** python manage.py runserver **

-------------------------------------------------------------------

// Migrations Django //
    __creéer les migrations__
        python manage.py makemigrations
    
    __Activer les migrations__
        python manage.py migrate
    
------------------------------------------------------------------

// CONNAITRE TOUS LES SUPERUSER, USER DE DJANGO //

    ** python manage.py shell -c "from django.contrib.auth.models import User; [print(u.username) for u in User.objects.filter(is_superuser=True)]" **

### CREER SUPERUSER ###
    ** python manage.py createsuperuser **
------------------------------------------------------------------

// INSTALLER LES DEPENDANCES //
    ** pip install -r requirements.txt **  # A FAIRE A CHAQUE NOUVELLE MACHINE #
    ** secretkey Django : python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())" **

## METTRE A JOUR LES DEPENDANCES ##
    ** pip freeze > requirements.txt **
    
------------------------------------------------------------------

## DOCKER ##
    ** docker-compose up **
    ** docker-compose up -d **
    ** docker-compose down **

------------------------------------------------------------------

## DATA TEST ##
    ** python manage.py loaddata fixtures/demo_data.json ** (importe les data de démo)
